# Pet Feliz — Fundamentos de Sistemas Web (Fase 1)

Projeto acadêmico de um site de petshop desenvolvido somente com HTML, conforme os requisitos da Fase 1.

## Arquivos
- `index.html`: página inicial.
- `produtos.html`: seis produtos em três categorias.
- `servicos.html`: serviços, preços e disponibilidade de tele-busca.
- `sobre.html`: apresentação e contato.
- `AJUDA.txt`: instruções de uso e descrição das páginas.

## Como visualizar
Abra `index.html` em um navegador.

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos deste projeto para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação e copie o endereço apresentado pelo GitHub Pages.

## Observações
Não há CSS, Bootstrap ou JavaScript nesta fase. As imagens são carregadas de URLs externas e precisam de internet. Os dados de contato e os preços são fictícios.
